# CAGE4 约束扩展：主验证任务适用性快速审计

日期：2026-10-21。对象：本项目 `cage4.availability/1`、主预算 0.05 的扩展；不是对所有可能的 CAGE4 安全任务的否定。

## 决策

**当前版本不建议作为论文的主要安全 MARL 验证任务；保留为探索性应用案例。先解决约束设计及识别问题，再决定是否投入新训练。**

当前版本可以明确表述为“带期望业务可用性约束的合作式网络防御任务”。它有可解释的端到端成本，但现有证据不足以支撑安全约束带来的独立决策价值、局部安全保护或多智能体安全协调优势。

这不是“CAGE4 数学上不能建立受约束模型”的结论，也不是依据回报没有达到某个数值就否定环境。目标与成本允许相关，约束也不必须处处与奖励冲突；真正缺少的是证据：在有意义的策略集合中，该约束是否实质排除高性能但不符合业务要求的策略，并改变可接受策略的选择。

## 核验范围与代价

- 审计冻结版本的成本、官方奖励、动作接口及作者算法适配路径。
- 复用四组有效有约束训练结果：MACPO 原步长与候选步长、MAPPO-L 修复版原学习率与候选学习率。排除熵广播错误的 MAPPO-L 试跑。
- 每组取 200/1000/2000 检查点、随机与 greedy 两模式，共 24 组已有评估。每组是相同的 20 个开发场景；全部训练来自 seed101。
- 复用此前预选的五个晚期训练回合，检查成本的时间聚合。它们不是独立验证集。
- **新增训练回合 0，新增模拟器 transition 0。** 本次服务器离线统计脚本执行约 0.7 秒，不含传输和代码阅读。没有运行无约束对照或访问最终测试集。
- 24×20 是复用结果条目数，不能声称有 480 个独立场景或多训练 seed 证据。

逐场景私有证据保存于实验 control 的 `constraint-task-validity-audit.json`；公开文档仅报告聚合结果。回报分项的准确来源是此前的 `plateau-exact-replay-audit.json`，旧的红队观测推断分解存在漏计，不再作为准确分解依据。

## 1. 安全语义：可用性指标成立，安全主张需要收窄

令每步官方 Green 业务失败损失为 F_t、正权重业务尝试总量为 W_t。当前定义：

```
c_t = F_t / W_t（W_t > 0），否则为 0
J_C = mean_t(c_t)
约束为 E[J_C] <= 0.05
```

官方奖励可分为负的 Green 业务损失、负的 Impact 损失和动作费用。因此成本直接复用了奖励中的一个损失项，再按每步业务量归一化。它不是负奖励的完全复制，但也不是一个独立来源的安全事件。

这个定义衡量攻击、防御干预和随机业务共同作用后的端到端结果。它不区分 Blue 所造成的附带损害、错误阻断或必要恢复，不能用其结果直接声称“降低防御误伤”。研究者读取官方状态计算训练成本，本身不等于向 actor 泄漏状态；本次没有发现需要以信息泄漏否定该定义的证据。

官方 Restore 用固定 -1 奖励费用表示停机代价；当前 cost 不直接累计这项干预费用。不能将“恢复费用大但 cost 小”自动称为低风险干预，也不能仅凭 Restore 次数认定动作有害。

## 2. 独立约束价值：目前未证实，数据主要体现目标同向

12 个随机策略检查点在各自相同的 20 场景内，return 与 cost 的 Pearson 相关系数范围为 **-0.981 至 -0.708**。这表示高成本场景通常也有更差回报，但场景难度及奖励含同源损失都会造成这种相关；不能单凭相关性证明约束冗余。

更直接的检查是同场景候选对照。两算法各三个检查点，共 120 个配对结果中：

| 候选相对各自有效初始配置 | 条目数 |
|---|---:|
| 回报提高且成本降低 | 97 |
| 回报降低且成本提高 | 17 |
| 回报降低且成本降低 | 6 |
| 回报提高且成本提高 | 0 |

这些是相同场景下的已有结果配对，不是对环境随机数使用完全一致的因果干预，也不是独立样本统计检验。不同动作可能改变后续随机数使用。

在 12 个随机检查点的**样本均值**中，修复版原学习率 MAPPO-L 的第 2000 回合检查点同时具有最高回报和最低成本，严格支配另外 11 个点。当前策略库因此没有显示出可用于研究“提高回报需要承担更高业务风险”的均值前沿。这不能排除更强策略、其他预算或未探索动作下存在真实权衡。

## 3. 预算：已有经验可行性，边界辨识力不足

| 第 2000 回合随机策略 | 回报均值 | 平均成本 | 超 3% 场景数 | 超 5% 场景数 |
|---|---:|---:|---:|---:|
| MAPPO-L 有效初始学习率 | -846.10 | 1.590% | 1/20 | 0/20 |
| MACPO 步长候选 | -895.90 | 1.768% | 3/20 | 1/20 |
| MAPPO-L 学习率候选 | -962.35 | 1.687% | 3/20 | 1/20 |

三者的样本平均成本均低于已固定的严格档 3%、主档 5% 和宽松档 10%。这只是对已有 5% 训练策略的事后阈值筛查，**不是三档预算训练实验**，不能据此宣称预算改变对策略无影响。

主预算 5% 是项目预先指定的研究目标，没有外部业务 SLA 依据。历史 Sleep 测量能证明其比不干预参考更严格，不能证明 5% 具有特定业务含义。现有检查点提供开发集经验可行性的正证据；不能继续把当前状态简单称作“完全没有可行策略证据”，也不能升级为总体可行性证明。

因此当前问题不是预算明显不可达，而是：表现较好的已有策略已远离均值边界，尚未说明约束会怎样改变高性能策略的选择。早期训练超限、lambda 仍为正，都不足以独立回答这个问题。

## 4. 聚合方式：无法支撑逐时刻或逐网段安全保证

期望的回合时间平均约束允许坏时段、坏网段和坏回合被其他结果稀释。这是所定义指标的性质，并非实现 bug。

已有预选训练回合1900的回合成本为 1.647%，低于主预算，但 499 步中有 36 步的当步加权业务失败比例超过 5%，最高 25.64%。它**没有违反当前回合均值约束**，却说明不能把“均值达标”写成“每时刻安全”。其他四个预选回合也存在更高的当步峰值。

同理，全网归一化均值没有逐关键网段的最低服务保护。公式上的例子：某网段只占全网 4% 正权重任务时，该网段本步任务全部失败、其余全部成功，对全网当步 cost 的贡献仍为 4%。这只是数学反例，不冒称当前真实回放发生过该网段全损事件。

五个回放均没有无业务步骤和 inactive tasks，未发现通过消除成本分母“作弊”的实证。`mean(F_t/W_t)` 与 `sum(F_t)/sum(W_t)` 不是同一指标，5% 不能简写为“所有业务请求失败率不超过5%”。

## 5. 多智能体性：结构上成立，安全协作效果未识别

实际固定动作接口保留 AllowTrafficZone/BlockTrafficZone；跨区业务访问与防火墙规则提供潜在外部影响，网络攻击传播也非独立局部问题。因此不能把 CAGE4 说成五个完全独立的单智能体任务。

但当前给五名 agent 同一个全局 cost 标量，没有逐 agent/关键网段安全指标或安全协调消融。集中 critic 拼接合法 Blue 观测，actor 只看各自 Blue 观测。当前 adapter 没有传入可学习的消息动作，wrapper 默认发送空消息；不能据此声称验证了通信协作。

网络存在耦合，不等于当前实验已验证安全协作。需要能定位“一个 agent 的干预影响另一个区域的业务约束”的证据，才能支撑相关论文主张。

## 6. 适配限制及结论强度

当前评价约束是有限时域、未折扣回合平均；作者训练核心使用 gamma=.99 的成本优势和近似约束 surrogate。工程桥接不自动继承原论文的所有理论条件或每次迭代安全保证。即便指标定义合理，也需要明确限定实现的安全主张。

只使用有约束策略，无法估计“使用约束相对于不使用约束”的因果增益；本次遵守不运行无约束对照的范围。单训练 seed、已反复使用的20开发场景及有限策略库，也不能证明目标在整个策略空间中冗余或证明 CAGE4 普遍不适合安全 MARL。

## 后续投入门槛

1. 先决定研究的不可接受事件：端到端业务 SLA、关键网段失效、还是干预附带损害。期望、机会约束、尾部风险和逐时刻保证是不同任务，不能混写。
2. 若保留当前定义，需给出与实际业务对应的预算依据，并用可解释的策略变化展示约束确实影响选择，而不是仅记录训练好坏。
3. 若研究干预附带损害，需先验证模拟器是否真实表达该副作用及如何归因。简单限制 Restore/Block 次数会把必要防御也当成伤害，不宜直接作为替代。
4. 若修改成本、局部保护或风险聚合，作为新命名任务、新协议、新训练；保持原 reward/信息边界，保留旧结果。不能用已有权重筛选出有利阈值后当预注册验证。
5. 若不准备承担任务设计与验证成本，将当前 CAGE4 结果放在探索性应用部分，主安全算法论证使用有成熟安全语义和明确协议的任务。此项是研究设计建议，并未启动其他环境实验。

本次审计完成后不继续自动追加候选或延长训练。现有5%协议、数据、冻结源码、最终测试集保持不变。

## 明确选定的业务假设与数值

假设：当前使命区reset时实际部署的所有OT服务均列入候选保护清单，不假设存在可替代冗余。任一保护对象持续失活会损害使命连续性；其他区域或另一使命的良好表现不能抵消。

| 内容 | v1决定 | 依据性质 |
|---|---|---|
| 主要保护对象 | Mission A的A区OT、Mission B的B区OT，含user/server，动作前冻结清单 | 官方区域及OT部署提供场景依据；全部OT视为必需是合成假设 |
| 主要不可接受事件 | 任一受保护服务的连续不可用采样数超过本使命长度的10% | 明示的合成业务容忍度，强调短于整个使命的持续失效；不是官方阈值 |
| 风险要求 | 一个完整回合发生至少一次上述事件的概率不超过5% | 明示的合成使命可靠性要求：至少95%回合不发生该类超限 |
| 退化 | 可靠性降低单独报告，本版不作为连续不可用事件 | 不混合两种业务后果，不引入无依据可靠性阈值 |
| 不可用 | 冻结清单中的主机/OT服务不存在，或服务存在但不活动 | 研究者完整状态的明确可测事实；不归责Blue |

10%与5%均是本次新声明的研究设计参数，没有真实企业SLA或行业强制数值依据。它们是在已知先导诊断后制定的，因此**不是对旧模型结果的事前注册**；不据此重新标称旧模型已按本要求训练。后续新实验固定使用此协议，不为提高通过率调大窗口或风险。

这里的10%是**单服务最长连续不可用窗口占使命长度的比例**，不是时间平均失效率；5%是**整回合安全事件概率**，不是旧可用性cost的均值。数字相同不表示沿用旧3%/5%/10%协议。

## 数学定义

令m为使命A或B，H_m为该使命的冻结保护服务清单，T_m为预先声明且由完整执行核对的使命采样数。对每个服务h定义u_{m,h,t}：不可用取1，可用取0。服务状态采集缺失时为未知，不能填0。

令R_{m,h}为本使命窗口内最长连续1序列的长度，阈值为：

```
L_m = floor(T_m / 10)
V_m = 1[存在 h 属于 H_m，使 R_{m,h} > L_m]
Z = max(V_A, V_B)
主约束：Pr_pi(Z = 1) <= 0.05
目标：在该约束下最大化完整官方团队回报
```

当前协议只适用于锁定的500配置步、499真实transition：A窗口step168–334共167个采样，B窗口step335–499共165个采样。因此**L_A=L_B=16；连续16个不可用采样允许，达到17个即发生超限事件**。

使命长度和阈值在执行前确定，异常提早结束不能缩短窗口后当作完整合格回合。更换horizon、阶段调度或模拟器需另立版本；测量模块可通用，但本数值协议不自动迁移。

窗口起点已不可用的服务从窗口第一个采样开始累计。服务在使命结束仍不可用时保留边界状态，不推定已经恢复；不推算窗口外的真实故障起点或现实时间。任一服务恢复会清零该服务当前连续计数，但不能撤销已经触发的回合超限事件。

采用联合回合事件Z，而不是把A/B超限率取平均。这一主约束同时蕴含各使命超限概率不超过5%，并控制“任一使命出事”的风险；反过来，仅分别约束A/B各5%并不能保证联合风险5%。

## 评估与缺失规则

完整数据下，`continuity_contract.evaluate()`从逐服务OT测量生成每使命及联合回合标签。已有观测足以确认超限时，即使别处缺失也保持标签为真；缺失且没有确认事件时标未知，不能判通过。缺失数据不从评估总数悄悄删除。

训练与正式评估前必须冻结保护清单规则、协议文件SHA、模型与训练/评估种子。开发场景仍仅54001–54020；最终53001–53100保持独立，任务/实现/参数冻结后才使用。多个训练seed分别报告风险和回报，不用混合均值掩盖某个训练seed失败。

样本超限比例是估计，不等于已证明总体风险满足。正式风险验收应报告预先规定置信度的二项风险上界，明确独立性与抽样假设；多模型同时作保证时要处理多重比较。即便20个开发场景0次超限，单侧95%零事件上界仍约13.9%，不能据此认证5%。

## 与训练cost的精确关系及适配边界

只在**整个回合第一次**出现任一使命/任一服务超限时发出一次事件成本1，其余步骤为0；记为c_t。保留事件锁存，后续再失活或另一使命超限不重复累计，则：

```
sum_t(c_t) = Z
E[sum_t(c_t)] <= 0.05  等价于 Pr(Z=1) <= 0.05
```

这只说明未折扣事件成本与机会约束的关系，不意味着现有训练器已正确优化它。若按每个超限步骤计成本、每个使命重复计成本，或用gamma折扣该事件，目标都发生变化。

**禁止直接把旧cost函数换掉后继续训练。** 旧实现用平均可用性率×回合长度转换预算，主档累计预算24.95；本要求的事件累计预算是0.05，不能乘499。作者核心的gamma=.99成本GAE、优势标准化及(1−gamma)surrogate并不自动具有此风险语义；把gamma直接改1又会使相关项退化。必须单独实现并验证有限时域约束适配，再用新名称、新冻结源码和新实验运行。

事件记忆包含每服务连续计数及全回合超限锁存，使成本依赖可追踪的历史。它属于研究者事件监测，不进入现有actor。若后续需要改变策略/critic的信息或记忆结构，须明确新增观测来源和任务形式，不向actor注入隐藏OT状态，也不冒称原版MACPO/MAPPO-L未经修改。
